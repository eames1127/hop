# Hop v0.9.0 (beta)

This is a beta for testers, ahead of v1. Hop is in daily use, but it edits your real SSH config,
so please read **Safety** below before you start. Feedback on anything that is wrong, confusing
or missing is very welcome.

## What Hop does

Hop shows the SSH hosts in your `~/.ssh/config` as cards and connects to any of them in one
click. It runs on Windows and Kubuntu (KDE Plasma), has no server, and your config stays the
single source of truth: plain `ssh <host>` keeps working exactly as before.

- Every host in `~/.ssh/config` (and its `Include` files) as a card with its description, tags,
  address and last-used time.
- **Connect** opens `ssh <host>` in Windows Terminal (or PowerShell) or Konsole. Kitty and XTerm
  can be chosen in settings.
- Add, edit and delete hosts with a form. Hop only ever rewrites the block you changed.
- Online checks, plus stale and missing-key flags, in a **Needs attention** list.
- A details panel showing what OpenSSH really uses (`ssh -G`) and a 30-day connection chart.
- Port forward shortcuts saved per host.
- A tray menu with favourites and recent hosts, and a quick-launch shortcut.
- SSH keys in settings: list public keys and fingerprints, make a new key, and add another
  computer's public key to chosen hosts. Hop never reads or moves a private key.
- Export hosts to a JSON file and import them on another computer. Keys are never copied.
- Light and dark themes.

## Installing

Download the file for your system from the assets below.

- **Windows:** the `.exe` (NSIS) installer. It is not signed yet, so Windows SmartScreen will
  warn that it is from an unknown publisher. Choose **More info**, then **Run anyway**.
- **Kubuntu:** the `.deb`, installed with:

  ```bash
  sudo apt install ./Hop_*.deb
  ```

- **Other Linux, or if the `.deb` gives you trouble:** the AppImage. Make it executable
  (`chmod +x ./*.AppImage`) and run it.

### Checking your download

`SHA256SUMS.txt` in the assets lists a SHA-256 checksum for every file. Because the installers are
unsigned, it's worth checking that yours matches before you run it.

- **Windows (PowerShell):** run `Get-FileHash .\Hop_0.9.0_x64-setup.exe` and compare the `Hash`
  with the line for that file (the case doesn't matter).
- **Linux:** put `SHA256SUMS.txt` in the same folder as your download and run
  `sha256sum --check --ignore-missing SHA256SUMS.txt`. It should print `OK` for your file.

If the checksum doesn't match, don't run the file. Download it again, and report it if it still
doesn't match.

## Known limits

- **Unsigned installer:** the Windows installer triggers a SmartScreen warning (see above).
- **KDE Wayland shortcuts:** global shortcuts are unreliable under Wayland, so Ctrl+Shift+H may
  not work. Add a custom shortcut in System Settings → Shortcuts that runs `hop --quick` instead.
- **No auto-update:** Hop does not update itself. Check the
  [releases page](https://github.com/eames1127/hop/releases) for new versions.
- **Read-only hosts:** only `Host` blocks with a single plain alias can be edited. Wildcard blocks
  (`Host *`), `Match` blocks and multi-alias hosts are shown read-only and never rewritten.
- **No macOS build.**

## Safety

Before every write, Hop copies the file it is about to change to
`config.hop-backup-<timestamp>` in the same folder (for example
`~/.ssh/config.hop-backup-20261106-120002`) and keeps the last 10. It then writes to a temporary
file and swaps it in, so a crash should never leave a half-written config.

Please also make your own copy of `~/.ssh/config` (and any `Include` files) before you try Hop.

To restore a backup, quit Hop (**Quit Hop** in the tray menu), then copy the backup over the
config:

```bash
cp ~/.ssh/config.hop-backup-20261106-120002 ~/.ssh/config
```

```powershell
Copy-Item "$HOME\.ssh\config.hop-backup-20261106-120002" "$HOME\.ssh\config"
```

## Reporting problems

Please open an issue at [github.com/eames1127/hop/issues](https://github.com/eames1127/hop/issues)
with your Hop version, operating system and the steps to reproduce.

Issues are public, so **don't paste your real SSH config, hostnames, IP addresses, usernames or
keys**. Swap in made-up values such as `example.com` or `192.0.2.10`.

For a security problem, don't open an issue: use private vulnerability reporting on the
repository's **Security** tab instead. See [SECURITY.md](https://github.com/eames1127/hop/blob/main/SECURITY.md) for details.
